## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly:
- **Maintainer**: Anton Barinov
- **GitHub**: [@Anton-Barinov](https://github.com/Anton-Barinov)

Please submit reports via GitHub Security Advisories or by contacting the maintainer directly. We will investigate and release a security advisory promptly.
